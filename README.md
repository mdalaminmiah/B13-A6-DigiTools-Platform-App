## 🛠️ Technology Stack

This project is engineered using a modern, full-stack architecture:

- **Frontend Framework:** React.js with DaisyUI components.
- **Styling Engine:** Tailwind CSS (Custom Linear Gradients & Responsive Utilities).
- **Backend Core:** ASP.NET Core (C#) for robust API handling.
- **Database:** Microsoft SQL Server with optimized T-SQL and SSRS Reporting logic.
- **Icons & Assets:** Font Awesome, Lucide-React, and high-quality custom PNG assets.

## ✨ Key Features

### 1. 💎 Premium Responsive UI & UX

Features a fully adaptive layout built with a **Mobile-First** approach. The UI includes custom linear-gradient themes (`rgba(79, 57, 246, 1)` to `rgba(149, 20, 250, 1)`) and advanced "Glassmorphism" elements that ensure a professional look on any screen size.

### 2. 📊 Enterprise Data Visualization

Integrated complex matrix-style reporting systems. Designed to handle large datasets with ease, providing users with clear, actionable insights through optimized SQL Server Reporting Services (SSRS) logic and dynamic data grids.

### 3. 🖱️ Interactive Micro-Animations

The platform features high-engagement components, including social link buttons with unique hover states (rotation, scaling, and color inversion). Every interaction is designed to provide tactile feedback to the user, enhancing the overall "premium" feel.
